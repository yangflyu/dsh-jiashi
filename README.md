# 架势画布（dsh-jiashi）

把**架势**的非线性画布接进 DeepSeek Harness：同一份对话，既能在原生聊天里线性读，也能在画布上摆成卡片；画布上输入的消息写回同一条 DSH 会话。

> *A nonlinear whiteboard for DeepSeek Harness sessions — cards on a tldraw canvas are display units of real DSH sessions, not a separate chat.*

> 当前版本 **v0.42.0**。当前进度/已知问题见 [docs/实施进度-压缩版.md](docs/实施进度-压缩版.md)，架构细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。
> 名字暂定 `dsh-jiashi`；「共工」（多人协作模式）是后续阶段。

## 为什么是画布（设计动机）

用 AI 处理"需要理解、而不只是要一个答案"的任务时，真正的流程通常是：

```
提问 Q → 尝试理解 → 没懂 → 定位分岔 → 追问 a1/b1/… → 再尝试理解 → 回到分岔处重读 …
```

AI 的一段回答简化后像一条推理链 `A → B → C → D`。看不懂的原因大致两类：不懂其中的名词概念（a1、b1…），或没看懂 `→` 这段推理。于是就要追问；追问本身又会长出新的没懂的点，对话因此像树一样分叉。等一条分支理顺，还要翻回之前的分岔处，带着新理解重读上一级回答——而**线性聊天里"定位分岔"极不丝滑**，再好的会话概览也只是把一条线摆得更整齐。

现实的三种应对都不便宜：硬扛着用；让 AI 换个说法重来（等于重开一条分支）；或者写一大段提示词限定"我已知什么"再问（更费时间和 token）。

矛盾不在模型，而在**界面**：有益的对话逻辑是树状/图状的概念网络，界面却是单链线性的。类比操作系统——命令行对熟练者很顺，但真正让大多数人把电脑融进生产生活的是图形界面与多重窗口。

所以本项目的设计是：

1. **画布空间**：每个文本框是一个节点，可自由摆放、连线；
2. **拖出即分叉**：选中回答里的文字直接拖到画布，即刻生成新框——可同会话、可另起会话，也可只是文本悬挂。把"提问 + 定位分岔"变成一次基于空间记忆的拖拽；
3. **卡片内可写**：自文本与对话块平级（问答之间可以随时写下自己的理解，不必切到笔记软件）；右键提供常用操作。*（v0.42 已实现基础版：条目化渲染 + 「＋ 对话块」，待实机验收；见 [实施进度 §7](docs/实施进度-压缩版.md)）*
4. **注意力模式**：向前兼容——聚焦一张卡就能回到熟悉的线性界面，两侧留出与其它卡片的关系；
5. **多人模式（共工，后续）**：如果单人这样交流体验成立，多人协作会是一个既新颖又有效的界面选择。

> 一句话：**把 AI 对话从"一条线"变成"一张可以摊开、可以走回去的图"。**

## 现在能做什么

- 左侧栏「画布」面板 → 工作区级 tldraw 画布（不是右侧栏，也不是对话的 View 标签）。
- **卡片 = 会话的显示单元**：一张对话卡绑定一条真实 DSH 会话，卡内线程实时显示消息/流式回复，输入框写回同一会话；卡头「打开」回到线性视图。
- **卡内条目平级交错**：一张卡的内容是「自文本 / 对话块 / 遗留 AI 卡」的有序列表——可以写一段自文本、接一段对话、再写一段、再开一段独立会话；每段对话块自带输入栏（v0.42，待实机验收）。
- **分段显示**：用户消息悬停「✂ 拆出」→ 右侧新卡（同一会话的下一段）；「⇤ 合并」拼回去。会话日志不动，拆分只是显示范围。
- **选字拖出成卡**：在 AI 回答里选中一段文字，点悬浮的「拖出成卡」或直接从选区按住拖出卡片外 → 生成一张小卡（360×160，自动避让原卡）；侧问卡**不继承主会话**，首次提问会新建自己的会话，主线不被打扰。
- **会话续接**：拉出/插入子卡、手动画箭头连接空白卡 → 自动继承同一会话，从父卡结束位置之后继续。
- **注入过滤**：DSH 注入的 runtime context / system-reminder / 技能清单 / 本轮时间等环境消息不会显示在画布上（会话数据不动，只影响显示）。
- **卡片拖动**：单击选中卡片后，框内任意位置都能拖动整卡；标题栏也可拖；双击进入编辑。
- **专注模式（单层）**：Alt+T 或工具栏「专注」聚焦一张卡，关联卡片按方向重排、其余淡化；专注中再聚焦另一张 = 切换焦点；Esc 直接回普通画布。专注状态跨面板切换保持。
- **持久化**：切走画布/刷新后，卡片、连线、绑定、拆分范围都还在（IndexedDB / tldraw persistenceKey）。
- **启动安全**：插件注册失败只写日志，不会阻断 DSH 启动。
- 原版架势能力保留：块级 Markdown 编辑、KaTeX、线性视图、快捷键设置、AI 设置面板（本地 AI 仅用于遗留卡片渲染）。

## 常用操作

| 操作 | 方式 |
|---|---|
| 新建对话卡 | 工具栏「＋ 对话卡」（新建 DSH 会话并绑定） |
| 新建普通文本方框 | 工具栏「＋ 文本方框」 |
| 把 AI 回答的一段拖成侧问卡 | 选中文字 → 点「拖出成卡」；或从选区按住拖出卡片外（Ctrl/⌘ 拖出 = 剪切） |
| 拆子框 | 双击文本 → 点进子框、光标放好 → **Ctrl/⌘ + Enter**（或块右上角「拆」） |
| 加一段对话块 | 双击卡片进入编辑 → 末尾「＋ 对话块」（新建独立会话；右键对话块可删除该条，不删会话） |
| 拆卡 / 合并 | 用户消息悬停「✂ 拆出」；分段卡头部「⇤ 合并」 |
| 清理空卡 | 工具栏「清理空卡」（删除无内容、未绑定会话的文本方框，可撤销） |
| 清空画布 | 工具栏「清空画布」（删除当前页所有卡片/连线，可 Ctrl+Z 撤销，不删 DSH 会话） |
| 专注模式 | 工具栏「专注」或 **Alt+T**，再按 Alt+T / Esc 退出 |

完整快捷键见画布「快捷键」面板。

> 拆子框还有一条走 DSH 命令注册表的快捷键 **Ctrl/⌘ + Shift + \\**（桌面端原生键盘桥分发，可在 DSH「设置 → 快捷键」改键）。`Ctrl/⌘ + \\` 被 DSH 自带的「拆分窗格」命令占用（原生层拦截，页面收不到），想用它拆子框可到 DSH 快捷键设置里清掉该绑定。

## 结构

| 文件 | 作用 |
|---|---|
| `index.js` | Host 半边：`/jiashi/api/log`（诊断日志）、`/jiashi/api/session/create`、`/jiashi/` 静态资源 |
| `src/client/index.jsx` | 客户端入口：注册面板、注入样式、标题 Context、快捷键、启动安全 |
| `src/jiashi/` | 架势源码（App / 组件 / 卡片 shape / 会话桥），改动尽量局部 |
| `src/jiashi/components/TextBlockContent.tsx` | 卡片内容：块级 Markdown 编辑、选字拖出、会话线程、拆分/合并入口 |
| `src/jiashi/shapes/TextBlockShapeUtil.tsx` | 卡片 shape：名片态、拉手、`createChildBlock` 统一拖出创建 |
| `src/jiashi/session/` | DSH 会话桥：`SessionThread`、`bridge.ts`（seq/会话 id）、`SessionInfo` |
| `lib/client.js` | 构建产物（DSH 客户端模块，约 5MB） |
| `scripts/build-client.mjs` | esbuild 构建脚本（CSS 文本化、KaTeX 字体内联） |
| `cordis.patch.yml` | 装配声明 |
| `docs/` | 实施进度（压缩版）、官方作者报名表等 |
| `web/` | 旧的 iframe 版构建，仅作历史对照 |

## 构建

```sh
node scripts/build-client.mjs
# 架势源码在别处时：
JIASHI_SRC=D:/path/to/Framework node scripts/build-client.mjs
```

依赖从 `JIASHI_SRC/node_modules` 解析；`react` / `react-dom` 由 DSH 宿主提供。

## 安装 / 更新

用 `plugin_manager install_bundle` 指向本目录（已装进 desktop profile）。
客户端代码更新后刷新一次 DSH 页面（或等 HMR 生效）即可；切一次左侧面板可强制重挂载画布。

## 排查

- 诊断日志：`C:\Users\<你>\.dsh\jiashi\board.log`（JSON 行）。常用事件：`module.load`（版本是否加载）、`activate.error`（面板注册失败）、`board.mount`、`diag.pointer`、`gesture.textdrag-*`、`pullout.create`、`attention.*`、`card.drag-end`、`session.*`。
- 启动失败：`%APPDATA%\@deepseek-ai\dsh-desktop\logs\crash-*-web-boot.log`；恢复对话框会禁用第三方插件并备份 profile patch。
